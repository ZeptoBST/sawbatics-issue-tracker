# sawbatics-issue-tracker
This repository serves to track bugs in Secret Agent Wizard Boy and the International Crime Syndicate: https://store.steampowered.com/app/3111080/Secret_Agent_Wizard_Boy_and_the_International_Crime_Syndicate/

Here are the different labels to use:
--------------------------------------------------------------

[Actors](https://github.com/ZeptoBST/sawbatics-issue-tracker/labels/Actors) =     When a bug relates to anything around npcs.

[Animations](https://github.com/ZeptoBST/sawbatics-issue-tracker/labels/Animations) =     When a bug relates to character animations.

[Audio](https://github.com/ZeptoBST/sawbatics-issue-tracker/labels/Audio) =     Anything related to audio, wether it's music or sfx.

[Collision](https://github.com/ZeptoBST/sawbatics-issue-tracker/labels/Collision) =     Anything related to model/object collision.

[Enhancement](https://github.com/ZeptoBST/sawbatics-issue-tracker/labels/Enhancement) =     For suggestions that can improve the game.

[Events](https://github.com/ZeptoBST/sawbatics-issue-tracker/labels/Events) =     If a bug is related to an event supposed to happen in-game (ex: the alarm going off when commiting a crime).

[FPS](https://github.com/ZeptoBST/sawbatics-issue-tracker/labels/FPS) =     Anything that has an effect on frame rate.

[Major Issues](https://github.com/ZeptoBST/sawbatics-issue-tracker/labels/"Major Issues") =     For bugs causing serious issues in the game, such as alting progression.

[Graphics](https://github.com/ZeptoBST/sawbatics-issue-tracker/labels/Graphics) =     Anything related to visuals/what you can see on-screen (ex: models, effects, particles...).

[Input](https://github.com/ZeptoBST/sawbatics-issue-tracker/labels/Input) =     Anything related to controls, wether it's Keyboard and mouse or controller.

[Likely Won't Change](https://github.com/ZeptoBST/sawbatics-issue-tracker/labels/"Likely Won't Change") =     When a bug is not going to be fixed.

[Missions](https://github.com/ZeptoBST/sawbatics-issue-tracker/labels/Missions) =     When a bug affects missions in the game (ex: shape key spawning in wrong location).

[Multiplayer](https://github.com/ZeptoBST/sawbatics-issue-tracker/labels/Multiplayer) =     Bugs that occur exclusively in multiplayer mode.

[Objectives](https://github.com/ZeptoBST/sawbatics-issue-tracker/labels/Objectives) =     Anything related to in-game achievements.

[Objects](https://github.com/ZeptoBST/sawbatics-issue-tracker/labels/Objects) =     Anything related to objects; anything from big objects (ex: cabinet, shopping kart, barrel...) to small objects (ex: apple, vase, breadstick...).

[Pending](https://github.com/ZeptoBST/sawbatics-issue-tracker/labels/Pending) =     When a bug is set to be fixed for a later build.

[Technical](https://github.com/ZeptoBST/sawbatics-issue-tracker/labels/Technical) =     Specifically for technical issues (ex: game crashes).

[UI](https://github.com/ZeptoBST/sawbatics-issue-tracker/labels/UI) =     Anything related to on-screen elements (ex: hud, menu, control prompts...).

[OOB](https://github.com/ZeptoBST/sawbatics-issue-tracker/labels/OOB) =     Anything related to on-screen elements (ex: hud, menu, control prompts...).

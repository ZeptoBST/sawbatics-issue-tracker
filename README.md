# sawbatics-issue-tracker
This repository serves to track bugs found in [Secret Agent Wizard Boy and the International Crime Syndicate](https://store.steampowered.com/app/3111080/Secret_Agent_Wizard_Boy_and_the_International_Crime_Syndicate/).

Here's how to report an issue:
--------------------------------------------------------------

1: Go to the [Issues](https://github.com/ZeptoBST/sawbatics-issue-tracker/issues) tab.

2: Click on the [New Issue](https://github.com/ZeptoBST/sawbatics-issue-tracker/issues/new/choose) button in the top right.

3: Fill out the template with the required informations. (Note that you can only upload files up to 10MB in size. It's recommended that you upload videos to YouTube and link them instead.)

4: Click on "Create" when you're done.


FAQ:
--------------------------------------------------------------

Q: How do I know if an issue already exists?

A: You can use the search box in the [Issues](https://github.com/ZeptoBST/sawbatics-issue-tracker/issues) tab to find an existing issue. Make sure to use key words (i.e: "biscuit", "cauldron", "broom", etc...) to narrow down the results.

----------

Q: I'm not sure if an issue already exists or not, what do I do?

A: When in doubt, report it anyway. If it did already exist, then it will be marked as "Duplicate" and will be closed. I'd rather people report duplicate issues than not reporting at all. Sometimes the devil's in the details.




Note:
--------------------------------------------------------------
If an issue lacks details enough or is unclear, it will make it more difficult for us to know what is being described.
We may ask for more details, but should that not be fulfilled we will have to close the issue.

It should also go without saying, but any spam or troll/fake issues will be closed, please make use of common sense.
